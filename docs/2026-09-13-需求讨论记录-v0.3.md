## 讨论过程与决策

### 第一轮：架构与范围

**Q1 架构走向**（登录注册 / 服务器历史 / 小程序 → 是否转向客户端-服务器架构）
→ 答：**先纯本地**。本轮只做不依赖服务器的本地改进，后端功能单独排期、届时再讨论架构。

**Q2 班级名与班级类型的关系**
→ 答：**班级名是新字段**。班级类型（1对1/1对2…）仍决定时薪；班级名只负责分组 / 配色 / 筛选。

**Q3 本期范围**（多选）
→ 答：**本地小改进**（班级名、背景色、日期筛选、输入框间距）。

### 第二轮：本地改进细节

**Q4 班级名在 Excel 的呈现**
→ 答：**新增一列班级名**，与「班级」列并存，共 11 列。
→ **2026-09-17 修订**：测试后改为 **Excel 不导出班级名**，保持 10 列；班级名仅用于预览表显示 / 配色 / 筛选。

**Q5 日期筛选是否影响导出**
→ 答：**筛选影响导出**。选某月后，导出只导出该月记录。

**Q6 班级名必填还是可选**
→ 答：**必填**。每条记录必须填班级名。

## 最终方案

### 数据模型

```python
@dataclass
class Record:
    date: date
    start_time: time
    hours: float
    class_type: str      # 班级类型，决定时薪
    class_name: str      # 班级名，必填，负责分组 / 配色 / 筛选
    note: str = ""
```

### 班级名输入方式

- 现阶段（无后端）：手动输入，做成「可编辑下拉」，记住本地已用过的班级名，重复班级可直接选
- 未来（后端上线后）：班级名改为从服务器存储的老师 / 班级 / 学生数据中选择

### 配色分组

- 按 `class_name` 分组，同班级名同色

### Excel 导出（10 列，A~J）

**不导出班级名**，班级列显示班级类型（1对1/1对2…）。导出范围跟随日期筛选。

### 背景色

换高对比调色板，~12 色。

### 日期筛选

预览区顶部下拉：全部 / 某月。筛选影响导出。
