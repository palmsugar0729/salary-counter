## 产品补充需求

2，背景色的色差再大一些，现在生成出来的效果有点差，相似度太高。

3，新增用户登录注册系统。注册时要求有用户名、真实姓名、密码、手机号和验证码。其中验证码由管理员账号生成；手机号用来区别同名同姓的老师；登录时输入用户名和密码即可。

4，新增账户管理界面，可以修改昵称、密码、手机号等。具体内容可以等功能稳定下来再添加。

5，新增设置界面，先做入口和暂定界面，具体内容等功能稳定下来再添加。

6，新增日期筛选记录功能。可以选择显示全部，也可以选择显示某一个月的。

7，新增微信小程序版本，有待后续开发。

8，新增课程管理界面，老师可以看到每天自己有哪些课；有签到、学生的课程情况和出勤情况记录等。管理员账号可以看到所有老师的课程，以及添加、修改、删除课程等；也可以录入学生、班级等。

9、如果有必要的话，会和另一个项目联动甚至合并（提出但不实行，暂且记录）。
